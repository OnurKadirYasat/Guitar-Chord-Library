# Guitar Chord Library

A simple React application to browse, search and manage guitar chords.

## Features
- Search chords by name
- Filter by difficulty
- Add/remove favorites
- Persist favorites using localStorage
- Toggle to show only favorite chords

## Tech Stack
- React
- JavaScript (ES6)
- CSS

## What I Learned
- Managing state with React (useState)
- Using useEffect for side effects (localStorage)
- Component-based architecture
- Building interactive UI with filtering logic
